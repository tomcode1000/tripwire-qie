DEVELOPERS

Four ways in. One command to start.

From no code to your own contract: protect a wallet, protect your AI agent's wallet, or refuse to pay thieves. Everything runs on QIE testnet today; mainnet is next.

npx github:tomcode1000/tripwire-qie --help
§ 01TWO KEYS

You need two keys. Only one can leak.

  • Everyday keyThe wallet you deploy with, the one that could leak. It owns your vault and can take out a small daily amount.
  • Backup keyA different wallet you keep offline. It controls the vault's rules, receives anything rescued, and sets the trap. A thief with your everyday key can't change anything.
§ 02COMMAND LINE

Protect a wallet, or an AI agent's wallet, from a terminal.

No install, Node 18 or newer. Keys are read from environment variables, never typed on the command line.

# 1. Create your vault. Big withdrawals will wait 24 hours. export TRIPWIRE_KEY=0x... # everyday key npx github:tomcode1000/tripwire-qie vault --backup 0xYourBackupAddress --delay 24h # 2. Make fake keys, offline. Each label says where you'll hide it. npx github:tomcode1000/tripwire-qie bait --label "github:my-repo/.env" --label "notes:keys.txt" # 3. Set the trap and let it lock your vault. Signed by your backup key. export TRIPWIRE_BACKUP_KEY=0x... npx github:tomcode1000/tripwire-qie arm --vault 0xYourVault # 4. Hide each .env file where its label says, then check on it any time. npx github:tomcode1000/tripwire-qie status --trap 0xYourTrap

For AI agents: plant a fake key next to the agent's real one on its server, keep its funds in a vault, and run check <payee> before every payment. Exit code 2 means don't pay. A full run of these commands on QIE testnet: recorded here.

§ 03THE BLOCKLIST

Refuse to pay a caught thief, in one line.

Free to read from any contract, app or agent. Blocklist on QIE testnet: 0xbFC006A0Becf8Dc567C09AA1f5A86fadeDA36F94

// Solidity interface IFlagRegistry { function isFlagged(address who) external view returns (bool); } require(!IFlagRegistry(BLOCKLIST).isFlagged(to), "blocklisted by Tripwire"); // ethers v6, in an app or an AI agent const list = new ethers.Contract(BLOCKLIST, ["function isFlagged(address) view returns (bool)"], provider); if (await list.isFlagged(payee)) throw new Error("payee is on the Tripwire blocklist"); // shell, in a deploy or payout script npx github:tomcode1000/tripwire-qie check $PAYEE || exit 1

Reading the history of catches: QIE's RPC rejects log queries wider than 10,000 blocks, so read Flagged events in windows.

§ 04THE WATCHER

Catch bots that sweep a fake key's QIE.

A sweep of native QIE is a plain transfer no contract sees. The watcher scans each block for transactions from your fake keys and reports them. It can only lock and blocklist, never move funds.

export TRIPWIRE_KEEPER_KEY=0x... # a small wallet with a little QIE for gas npx github:tomcode1000/tripwire-qie watch --trap 0xYourTrap
