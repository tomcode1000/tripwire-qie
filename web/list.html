Refuse a flagged address in one line

The registry is a public good: free to read, from a contract, an app or an AI agent. Check before you pay, list or airdrop.

interface IFlagRegistry { function isFlagged(address who) external view returns (bool); } // Solidity require(!IFlagRegistry(REGISTRY).isFlagged(to), "flagged by Tripwire"); // ethers v6 const r = new ethers.Contract(REGISTRY, ["function isFlagged(address) view returns (bool)"], provider); if (await r.isFlagged(payee)) throw new Error("payee took Tripwire bait");
